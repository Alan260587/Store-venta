## Cómo desplegar en Vercel desde GitHub (Recomendado)

El proyecto ya cuenta con **`vercel.json`** y **`.npmrc`** configurados automáticamente para **Vercel**:

1. En **Google AI Studio**, haz clic en el ícono de **GitHub (Export to GitHub)** arriba a la derecha para subir/actualizar tu repositorio.
2. Entra a [vercel.com/new](https://vercel.com/new) e importa tu repositorio de GitHub.
3. No necesitas cambiar ningún ajuste manual: Vercel detectará automáticamente `vercel.json` (`Framework: Vite`, `Install Command: npm install --legacy-peer-deps`, `Build Command: npm run build`, `Output Directory: dist`).
4. Haz clic en **Deploy** y tu tienda + catálogo de 148 páginas quedarán publicados en vivo.
