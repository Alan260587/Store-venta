## Cómo actualizar y desplegar en GitHub / GitHub Pages

Este proyecto incluye el flujo automático de despliegue en `.github/workflows/deploy.yml`.

### Desde Google AI Studio (1 clic)
1. En la barra superior derecha de **Google AI Studio**, haz clic en el ícono de **GitHub (Export to GitHub)**.
2. Selecciona tu repositorio o crea uno nuevo y haz clic en **Push / Export**.
3. En tu repositorio de GitHub, ve a **Settings** → **Pages** y asegúrate de que **Source** esté en **GitHub Actions**.
4. El workflow `Deploy Sheló NABEL App to GitHub Pages` compilará y actualizará automáticamente tu sitio web en vivo.
